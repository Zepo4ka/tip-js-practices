## 4. Модель данных и функции

Задача содержит четыре поля:

- `id` — положительное безопасное целое число; в списке не повторяется.
- `title` — строка от 1 до 100 кодовых единиц UTF-16 после `trim()`. Внутренние пробелы сохраняются.
- `completed` — логическое значение; новая задача создаётся со значением `false`.
- `priority` — `low`, `medium` или `high`; по умолчанию `medium`.

Строковые идентификаторы и статусы не преобразуются в числа или логические значения.

| Функция | Назначение и результат |
|---|---|
| `createTask` | Проверяет аргументы, возвращает `{ ok: true, task }` с новым объектом. |
| `findTaskById` | Использует `find`, возвращает исходный объект с совпадающим числовым `id` либо `undefined`. |
| `getPendingTasks` | Использует `filter`, возвращает новый массив невыполненных задач. |
| `getTaskTitles` | Использует `map`, возвращает новый массив названий в исходном порядке. |
| `getTaskStats` | Возвращает числа `{ total, completed, pending, progress }`. Для пустого списка все поля равны нулю. |
| `addTask` | Создаёт задачу через `createTask`, проверяет уникальность `id`, добавляет её в конец нового массива через spread. |
| `setTaskCompleted` | Возвращает новый массив через `map`, копирует выбранную задачу через spread, изменяет только статус. |
| `renameTask` | Проверяет и очищает название, возвращает новый массив и новый объект выбранной задачи. |
| `removeTask` | Удаляет запись через `filter`, сохраняя порядок остальных задач. |

При ошибке создания или изменения возвращается `{ ok: false, error }` с понятным сообщением.
Все четыре операции изменения при успехе возвращают `{ ok: true, tasks }`.
Повторное присваивание прежнего названия или статуса тоже создаёт новый массив и новый объект выбранной записи.

Распределение файлов:

- [data.js](./src/data.js) содержит общий набор и шесть задач варианта 5.
- [task-service.js](./src/task-service.js) содержит девять функций, проверяет данные и возвращает результаты.
- [main.js](./src/main.js) выполняет сценарии, обрабатывает отказы и выводит результаты.
- [checks.js](./checks.js) — неизменённые проверки из стартового комплекта преподавателя.
- [own-checks.js](./own-checks.js) — три дополнительные проверки с `node:assert/strict`.

`id` сохраняет смысл после удаления соседней задачи, а индекс может поменяться. Поэтому поиск выполняется по полю `id`.
Сводка возвращает процент числом без округления; только при выводе в `main.js` применяется `toFixed(1)`.
Деструктуризация используется в `showStats` для получения четырёх полей сводки.

При обновлении копируется массив и выбранный объект. Неизменённые объекты можно использовать повторно.
Сохранность проверяется сравнением полей со снимками до вызова и отдельной проверкой ссылок.
